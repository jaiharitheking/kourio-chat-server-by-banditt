# 💬 Kour.io Private Chat System

> Real-time signaling server for Kour.io private chat system with offline messaging, groups, and polls. Built with WebSocket for instant peer-to-peer communication.

**Created by [Banditt](https://github.com/jaiharitheking)**

---
 ✨ Features

- ✅ **Private Messaging** — 1-on-1 chats with friends
- ✅ **Offline Messages** — Messages are stored when you're offline and delivered when you come back
- ✅ **Group Chats** — Create groups and chat with multiple people
- ✅ **Polls** — Create polls and vote in real-time
- ✅ **Contact Management** — Add, remove, and block contacts
- ✅ **Typing Indicator** — See when someone is typing
- ✅ **Read Receipts** — Know when your messages are read
- ✅ **Zero Configuration** — Just install the TamperMonkey script and use it
- ✅ **Free Forever** — No credit card required
